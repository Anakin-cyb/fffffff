# Hardware Confirmation Checklist

Before final firmware/GPIO code, record:
- exact ESP32 board model
- exact GPS module model
- exact LoRa module model and interface
- exact OLED/display model
- exact Raspberry Pi model
- exact Raspberry Pi Camera model
- exact relay board model and coil/logic voltage
- exact gas sensor model
- exact heat sensor model
- exact DFPlayer Mini wiring
- exact display wiring
- exact button wiring
- exact status LED wiring
- exact microSD modules/cards
- exact logic-level converter wiring
- power supply/ground topology

Attach clear photos/video of the actual wiring before pin-specific code is finalized.
