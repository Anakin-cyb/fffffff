# Demo Flow

1. Show NORMAL signal state.
2. Activate vehicle emergency switch.
3. Show vehicle ID + GPS request.
4. Show verification result on control room.
5. Approve from control room or approved physical workflow.
6. Traffic Node creates event ID.
7. Camera starts recording.
8. Signal enters green corridor.
9. AI counts passing vehicles.
10. Sensors and audio operate.
11. Press NORMAL / finish corridor.
12. Display shows restoration countdown and next signal.
13. Evidence package is saved.
14. Show event history and forensic records.
