# Traffic Node UI

Suggested display pages:
1. Signal: current state, next state, countdown
2. Environment: temperature, gas, heat status
3. AI: camera status, detection state, vehicle count
4. Emergency: request ID and approval state
5. Evidence: event ID, recording, SD status
6. System: LoRa, camera, storage, AI health

Suggested physical buttons:
- REQUEST
- APPROVE
- NORMAL

Suggested status LEDs:
- REQUEST
- APPROVED
- RECORDING
- FAULT

After corridor closure, explicitly show normal traffic restoration and next signal/countdown.
